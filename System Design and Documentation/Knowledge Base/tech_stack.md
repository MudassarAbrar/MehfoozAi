React 19 + Vite 6 + TypeScript 5.8 with Tailwind CSS v4 via `@tailwindcss/vite`; Express 4 server with helmet and express-rate-limit; Google GenAI SDK (`@google/genai`) for Gemini function-calling and embedding retrieval; Supabase JS client for auth and RLS-backed data; Leaflet + OpenStreetMap for maps; motion/react v12 for animations; jspdf for PDF export; twilio and resend for SMS/email dispatch; vite-plugin-pwa for PWA installability.
