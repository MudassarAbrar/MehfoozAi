`npm run dev` runs `tsx server.ts`, which starts both the Express backend and Vite dev server on port 3000. Production build runs `vite build && esbuild server.ts --bundle --platform=node --format=cjs --packages=external --sourcemap --outfile=dist/server.cjs`, then `node dist/server.cjs` starts the compiled server. Requires a `.env` file with `GEMINI_API_KEY` (optional — without it the server returns a fallback flag and the client uses the local deterministic legal engine); optional `SUPABASE_*` env vars enable Supabase auth/RLS.
